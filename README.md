# 衡资 0.2.1

Node.js 22.5+；无需第三方 npm 依赖。

## 启动

```bash
git clone https://github.com/jiaqiang-coder/finance-management.git
cd finance-management
APP_PASSWORD="请换成强密码" npm start
```

未设置 APP_PASSWORD 时仍使用开发密码，正式部署必须设置强密码。默认监听 127.0.0.1:4173。访问路径为 /app/fm/，生产需通过 HTTPS 代理访问。

## 本次完善

- 新增及编辑资产/负债账户：名称、分类、币种、原币金额、备注、估值方式。
- 人民币、美元、港币录入；自动模式由服务端折算，不信任客户端人民币估值。
- 汇率管理：官方报价日、获取时间、来源、最近90个报价日历史、最近7次自动同步状态。
- 欧洲央行 ECB 官方 XML：https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml 。以欧元参考汇率交叉计算 USD/CNY 与 HKD/CNY。
- 每天北京时间01:10自动同步。服务器晚启动会补跑当天任务；失败会记录，保留旧值，可手动重试。周末及休市日沿用最近交易日报价，不冒充当日报价。
- 原有账户默认保持手动估值；编辑时可改为自动。更新只重估自动模式账户，不改历史流水。
- 不再自动填充演示数据；历史趋势尚未实现，显示明确空状态，移除虚构指标。

## 持久化

SQLite：data/hengzi.db。汇率缓存、报价历史、自动任务状态均入库。Docker需挂载此目录；重启/更新不要删除该目录。持久化不等于备份。

## 更新已有服务器

将同包 hengzi-display-fix.py 上传到服务器 /tmp，执行 sudo python3 /tmp/hengzi-display-fix.py。脚本会备份数据库与旧代码，保留现有业务记录，更新衡资源码后重启 hengzi-fm。不会修改博客、sub2api 或 Caddy。完成后强制刷新浏览器。

## 验证

项目目录执行 npm test；前端逻辑测试使用 DOM 桩，接口测试使用临时数据库与确定性ECB格式样本，包含更新失败、账户编辑及进程重启持久化。测试不等于线上浏览器验收。

## 尚未实现

历史估值趋势、PDF报告、真实证券行情、自动备份和正式身份系统仍需完善；不以演示数值代替真实数据。收支报告当前的服务端日期范围仍为原版本固定月份，后续需改为动态统计周期。

## 预算设置

在预算预警页点击预算设置可新增分类预算，也可选择已有预算或点击分类行的编辑按钮修改。金额为人民币，必须大于0；预警阈值为1%至100%。分类名需与流水分类一致；同名分类不可重复创建。预算支出按北京时间当前自然月统计，修改后会重新计算总览预警。
